# 个人主页（课程作业）

一个纯静态的个人主页，用于课程作业展示。无需任何框架或构建工具，双击即可在浏览器打开。

## 一、项目简介

本页面面向"新人"定位，围绕一个核心目标设计：**让访客在 30 秒内认识「你是谁、你想做什么、你能做什么、你做过什么」**。

页面按"身份 → 动机 → 规划 → 能力 → 证据"的逻辑链，划分了五个信息板块：

1. **个人基本信息** —— 头像、姓名、专业、一句话简介、联系方式。
2. **兴趣方向** —— 一排兴趣标签。
3. **我想做的三个项目** —— 三张卡片，展示规划与目标。
4. **技能卡片** —— 四项技能 + 熟练度进度条。
5. **作品区** —— 三件作品，支持按分类筛选。

技术栈仅使用原生 HTML、CSS、JavaScript，不引入任何框架、外部 CDN 或远程资源，保证离线双击可用。

## 二、文件结构

```
Task01-profile/
├── index.html    # 页面结构与内容（五大板块的语义骨架 + 可直接改的静态文字）
├── style.css     # 整站样式：配色变量、卡片网格布局、深/浅主题配色、响应式
├── script.js     # 交互逻辑：项目卡片展开、头像上传、主题切换、作品筛选
├── avatar.jpg    # 默认头像图片（未上传时显示，可替换为自己的图片）
└── README.md     # 本说明文档
```

| 文件 | 职责 | 是否常改 |
|---|---|---|
| `index.html` | 结构 + 静态内容（基本信息、兴趣、项目简介、作品文字） | 是 |
| `style.css` | 视觉与主题（顶部 `:root` 变量集中控制配色） | 偶尔 |
| `script.js` | 所有交互行为，可编辑数据集中在文件顶部 | 偶尔 |
| `avatar.jpg` | 默认头像 | 可选 |

## 三、运行方法

1. 将 `Task01-profile` 文件夹整体保留（不要拆散文件，相对路径才能正确加载）。
2. 双击 `index.html`，即可在默认浏览器中打开。
3. 无需安装依赖、无需启动服务器、无需联网。

> 提示：若修改后页面无变化，按 `F5` 或 `Ctrl + R` 刷新；浏览器缓存严重时可尝试硬刷新（`Ctrl + Shift + R`）。

## 四、实现功能

### 基础展示（静态）
- 五大信息板块，电脑端正常浏览，布局简洁。
- 头像使用 `avatar.jpg` 显示；技能、作品缩略图使用 CSS 渐变占位，缺图也不会出现裂图。

### 交互功能（共 4 个，均可重复使用）

| 功能 | 触发方式 | 行为说明 | 刷新后 |
|---|---|---|---|
| 项目卡片展开 / 收起 | 点击任一项目卡片 | 在「展开详细描述 ↔ 收起」间切换，提示文字同步变化 | 全部回到收起（初始状态） |
| 头像上传 / 更换 | 点击顶部头像圆圈 | 打开文件选择，选中图片后显示在圆内；可多次更换 | 保留上次上传的头像 |
| 深 / 浅主题切换 | 点击右上角「切换主题」按钮 | 整页在深色与浅色间切换 | 保留上次选择的主题 |
| 作品区筛选 | 点击分类按钮 | 只显示所选分类作品；「全部」显示所有；可反复切换 | 回到「全部」（初始状态） |

### 四个交互的执行要点
- **项目卡片**：详细描述文字来自 `script.js` 顶部的 `projectDetails` 数组，按卡片顺序对应；展开状态靠内联样式切换，不修改 HTML 结构。
- **头像上传**：用 `FileReader` 读取图片并以 base64 存入 `localStorage`，刷新后自动恢复；默认头像为 `avatar.jpg`。
- **主题切换**：给 `<html>` 切换 `dark` 类，CSS 中 `html.dark` 覆盖配色变量；主题偏好存入 `localStorage`。
- **作品筛选**：按按钮的 `data-filter` 与各作品的 `data-category` 匹配，显示/隐藏对应作品；未持久化，刷新回到全部。

## 五、自定义修改指南

以下位置均已在源码中标注，方便自行改动。

### 1. 页面主标题（修改点 1）
`index.html` 中 `class="main-title"` 的 `<h1>` 文字，即 `你好，我是吴佳敏`，改为自己的姓名或标语。

### 2. 技能卡片背景色（修改点 2）
`style.css` 中 `.skill-card` 规则里设置了背景色变量，直接改该值即可统一调整技能卡底色。

### 3. 项目一简介文字（修改点 3）
`index.html` 中「项目一」卡片里的 `<p>` 描述文字，替换为自己的项目说明。

### 4. 更换默认头像
将一张图片命名为 `avatar.jpg` 覆盖原文件，或修改 `index.html` 中 `<img id="avatarImg" src="avatar.jpg">` 的 `src` 路径。

### 5. 修改项目详细描述 / 作品筛选分类
- 项目详细描述：改 `script.js` 顶部 `projectDetails` 数组内的三句话。
- 作品分类：在 `index.html` 的 `.filters` 与 `.work` 上增减按钮与 `data-category` 值（需一一对应）。
- 主题深色配色：改 `style.css` 末尾 `html.dark` 下的颜色变量。

## 六、注意事项

- 上传的头像保存在浏览器本地（`localStorage`），换浏览器或清除浏览器数据后会回到默认头像 `avatar.jpg`。
- 所有交互逻辑均包裹在 `try/catch` 中，在 `file://` 直接打开（部分浏览器限制本地存储）时也不会报错。
- 本项目不依赖任何第三方服务，适合作为课程作业直接提交与演示。
